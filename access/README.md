# Контрольные задания по Microsoft Access (задания 01–10)

Все десять контрольных заданий из практикума («Контрольные задания», с. 50–52) выполнены
по образцу учебной базы «Успеваемость студентов» и объединены в одну базу данных.
Задания открываются из одной общей управляющей формы **«Главная»** (как на рис. 66 практикума).

Для каждого задания созданы:

- **таблицы** с ключевыми полями и полями со списком (подстановками);
- **схема данных**: связи «один-ко-многим» с обеспечением целостности и каскадным обновлением
  (где нужно — с каскадным удалением);
- **тестовые данные**;
- **запросы**: на выборку, с группировкой и подсчётом (Count/Sum), с вычисляемыми полями,
  «без подчинённых», перекрёстные, запросы с условием отбора из управляющей формы
  (`[Forms]![Управляющая]![Поле]`, как на рис. 65);
- **формы** для ввода и просмотра данных, часть из них с подчинёнными формами;
- **отчёты** с группировкой, нумерацией записей внутри группы (`=1`, «Сумма с накоплением —
  для группы»), подсчётом количества в группах и всего;
- **управляющая форма задания** `З0N_Управляющая`: поля со списком для выбора параметров
  и кнопки «Ввод и просмотр данных», «Получение запросов», «Получение отчетов».

Код один: модуль VBA `modBuild.bas` строит всю базу автоматически, вручную ничего создавать не нужно.

## Как получить готовую базу `.accdb`

1. Запустите Microsoft Access (2010 или новее) и создайте **пустую базу данных**, например
   `Контрольные задания.accdb`.
2. Нажмите **Alt+F11**, откроется редактор VBA.
3. **File → Import File…** (Файл → Импорт файла…) и выберите `access/modBuild.bas`.
   В проекте появится модуль `modBuild`.
4. Проверьте **Tools → References** (Сервис → Ссылки). В новой базе `.accdb` там уже отмечена
   библиотека *Microsoft Office xx.0 Access database engine Object Library* (DAO).
5. Поставьте курсор внутрь процедуры `BuildAll` и нажмите **F5**.
   Построение займёт примерно минуту. После этого появится сообщение «База данных построена»,
   и откроется форма **«Главная»**.
6. Закройте редактор VBA и сохраните базу. Форма «Главная» уже назначена формой запуска.
   При следующем открытии базы нажмите **«Включить содержимое»**: без этого кнопки
   управляющих форм не работают.

> **Важно.** Модуль сохранён в кодировке Windows‑1251, потому что в нём русские имена объектов.
> В Windows должен быть выбран русский язык для программ, не поддерживающих Юникод:
> *Панель управления → Региональные стандарты → Дополнительно*.

Процедуру `BuildAll` можно запускать повторно. Она удаляет объекты, созданные ранее
(`З01_…` – `З10_…`, форма «Главная»), и строит их заново.
Связи видны в окне **Схема данных** по кнопке **«Все связи»**.

Если что-то пошло не так, сообщение об ошибке покажет шаг, на котором она произошла:
имя таблицы, запроса, формы или отчёта.

## Как пользоваться

**Главная** → кнопка «Задание NN» → открывается управляющая форма задания:

- вверху выбираются параметры: группа, преподаватель, период, специальность, читатель и т.п.;
- колонка **«Ввод и просмотр данных»** открывает формы для ввода данных;
- колонка **«Получение запросов»** открывает запросы;
- колонка **«Получение отчетов»** открывает отчёты в режиме предварительного просмотра;
- кнопка **«<< Главное меню»** возвращает на форму «Главная».

Если для запроса или отчёта нужен параметр, а он не выбран, форма попросит его выбрать.

## Состав заданий

Все объекты задания N имеют префикс `З0N_` (у задания 10 — `З10_`).

### Задание 01. «Расписание занятий»
- **Таблицы:** Группы, Аудитории, Преподаватели, Дисциплины (часы по плану), Пары (расписание звонков),
  Календарь (на семестр с 1 сентября, 17 недель), Занятия (дата, пара, группа, дисциплина,
  преподаватель, аудитория, вид занятия). Занятия генерируются по недельному шаблону на весь семестр.
- **Запросы:** Занятия подробно; Часы групп по дисциплинам (план и факт); Часы преподавателей
  по дисциплинам; Нагрузка преподавателей; Часы аудиторий; Сводная (перекрёстная): часы групп;
  Расписание группы / преподавателя / аудитории за выбранный период.
- **Отчёты:** Расписание группы, преподавателя, аудитории (группировка по дате);
  Часы групп по дисциплинам; Часы преподавателей по дисциплинам; Занятость аудиторий.

### Задание 02. «Абитуриенты»
- **Таблицы:** Населённые пункты, Специальности (план приёма), Абитуриенты (средний балл,
  дата рождения, адрес, телефон).
- **Запросы:** количество абитуриентов по населённым пунктам и по специальностям (с конкурсом
  на место); отличники, хорошисты, троечники (вычисляемое поле `IIf` по среднему баллу);
  перекрёстный «пункты × специальности»; списки по специальности и по категории; именинники месяца.
- **Отчёты:** Количественный состав абитуриентов; Абитуриенты по успеваемости и по населённым
  пунктам; Список абитуриентов специальности; **Поздравление с днём рождения**.

### Задание 03. «Телефонная книга»
- **Таблицы:** Факультеты → Группы → Студенты; Населённые пункты.
- **Запросы:** Телефонная книга; поиск телефона и адреса по фамилии; поиск фамилии и адреса
  по номеру телефона (`Like`); студенты группы; студенты из населённого пункта; количество
  студентов по группам.
- **Отчёты:** Телефонная книга студентов (группировка по первой букве фамилии); Студенты
  по факультетам и группам; Список студентов группы; Студенты населённого пункта.

### Задание 04. «Учебные планы»
- **Таблицы:** Специальности, Дисциплины, Семестры, Формы контроля (зачёт, дифзачёт, экзамен),
  Учебный план (лекции, практикум, самостоятельная работа, форма контроля).
- **Запросы:** учебный план с вычисляемыми полями «Аудиторных» и «Всего»; план специальности;
  план на семестр; итоги по семестрам (часы, число экзаменов и зачётов); сводный план
  (перекрёстный: дисциплины × семестры); формы контроля по специальностям; дисциплины вне планов.
- **Отчёты:** Учебные планы специальностей на все семестры (две группировки, суммы часов);
  Учебный план специальности; Итоги по семестрам.

### Задание 05. «Сотрудники»
- **Таблицы:** Отделы, Образование (уровень: высшее или среднее), Населённые пункты, Сотрудники.
- **Запросы:** общее количество сотрудников (всего, с высшим и со средним образованием);
  количество по отделам; количество по уровню образования; перекрёстный «отделы × образование»;
  сотрудники отдела; сотрудники населённого пункта; именинники месяца.
- **Отчёты:** Сотрудники по отделам; Сотрудники по образованию; Список сотрудников отдела;
  Сотрудники населённого пункта; **Поздравление с днём рождения** выбранного сотрудника.

### Задание 06. «Выпускники»
- **Таблицы:** Специальности, Организации (места работы), Выпускники (год выпуска, место работы,
  должность, работа по специальности).
- **Запросы:** количество выпускников по институту (всего, трудоустроенных, безработных,
  % трудоустройства); по статусу; **востребованность специальностей** (рейтинг по проценту
  трудоустройства); списки безработных и трудоустроенных; трудоустройство по отраслям;
  перекрёстный «специальности × годы»; выпускники специальности; выпускники года.
- **Отчёты:** Выпускники по специальностям; Трудоустройство выпускников;
  Востребованность специальностей; Выпускники специальности.

### Задание 07. «Преподаватели»
- **Таблицы:** Кафедры, Учёные степени, Преподаватели, Дисциплины, Преподавание
  (связь «многие-ко-многим» преподавателей и дисциплин).
- **Запросы:** общее количество преподавателей; количество по дисциплинам; количество
  с учёными степенями; **дисциплины без преподавателей** (запрос «без подчинённых»);
  преподаватели дисциплины; преподаватели с учёными степенями; кафедры и количество
  преподавателей; преподаватели кафедры; перекрёстный «кафедры × степени».
- **Отчёты:** Кафедры и преподаватели; Преподаватели по дисциплинам; Преподаватели
  с учёными степенями; Список преподавателей кафедры.

### Задание 08. «Библиотека»
- **Таблицы:** Рубрики, Книги (инвентарный номер, автор, издательство, год), Читатели,
  Выдачи (дата выдачи, срок, дата возврата).
- **Запросы:** книги на руках; каталог с наличием («В наличии» / «На руках» у кого);
  количество книг всего и по рубрикам; **есть ли книга, у кого на руках** (поиск по названию);
  книги рубрики, автора, издательства, года; книги, числящиеся за читателем; просроченные книги.
- **Отчёты:** Библиотечный фонд по рубрикам; Книги на руках у читателей; Формуляр читателя;
  Книги рубрики.

### Задания 09 и 10. «Издательский отдел» и «Информационный отдел»
Структура одинаковая. В задании 09 учитываются печатные издания (страницы, тираж), в задании 10 —
электронные материалы (формат, объём, ссылка).
- **Таблицы:** Кафедры, Преподаватели, Типы изданий, Дисциплины, Издания, Авторство
  («многие-ко-многим»: у издания несколько авторов).
- **Запросы:** издания подробно (список авторов собирает функция VBA `AuthorsList`); перечень
  по кафедрам и дисциплинам; количество изданий кафедр и университета за выбранный год
  и за последние 5 лет; перекрёстный «кафедры × годы»; перечень и количество по типам
  за период; перечень и количество изданий автора за период.
- **Отчёты:** Издания по кафедрам и дисциплинам; Издания за последние 5 лет (итоги
  по кафедрам и всего); Издания по типам за период; Издания автора за период.
